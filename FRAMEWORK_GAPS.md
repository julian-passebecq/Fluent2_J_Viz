# Framework gaps and follow-up boundaries

This records evidence limits; it is not a request to patch Datapass.

| Item                           | Current evidence                                         | Required next evidence                                                         |
| ------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------ |
| External renderer registry ABI | Names and baseline supplied in the pack                  | Exact confirmed framework SHA, adapter shape and real FigureView demonstration |
| Consumer bootstrap/scaffold    | Pending in the brief                                     | Official external-consumer mechanism and generic workbench scaffold choice     |
| Framework package/token pin    | Intentionally absent                                     | Deliberately pinned dependency + consumer lockfile after seam confirmation     |
| Generic code editor            | Local textarea is sufficient for standalone spec editing | Confirmed `@datapass/code` JsonSpecEditor integration                          |
| Host playback ownership        | VizForge exposes one deterministic StoryPlayer           | Confirmed binding to any generic FigurePlayer, with no competing timers        |
| Cross-host theme mapping       | Semantic renderer roles work locally                     | Map confirmed generic tokens and recheck contrast in the real host             |
| Power BI packaging             | Adapter plan only                                        | Separate authorized packaging and host-specific tests                          |

V1 chart limitations are explicit: simple geographic/schematic maps, directed acyclic flows, numeric time, sum/unweighted mean matrix aggregation, and family-specific encodings. Dense scientific labeling, tiles, complex projections, weighted-ratio expressions and interactive cell editing are outside this first contract. These are product boundaries, not hidden dependencies on framework changes.
