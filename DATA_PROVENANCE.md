# Pinned demonstration data

V1.2 preserves all 22 deterministic synthetic examples and adds four real-data stories. No canonical example downloads data at runtime. The production browser gate rejects external requests while traversing every flagship scene.

The authoritative dataset manifest is [data/provenance.json](data/provenance.json): exact acquisition URLs, UTC retrieval timestamps, organization, license/usage notes, fields/units, missing-value rules, transformations, raw SHA-256 and extracted SHA-256. Studio dates use Europe/Zurich: the numerical snapshots were pinned on 6 September locally (5 September late evening UTC). Hashes use UTF-8 with LF newlines; `.gitattributes` preserves that convention. [docs/DATA_PROVENANCE.json](docs/DATA_PROVENANCE.json) separately hashes all 26 canonical StorySpecs and labels synthetic versus real.

The GDP selection is deliberate, not a claim to be a complete world ranking. Current-dollar GDP combines output, prices and exchange rates; it is neither real growth nor GDP per capita. The composition denominator is **only the five selected economies**, never world GDP. Rank arrows compare with the previous annual observation, even when chapters skip years. Claims in captions are calculated from the pinned values.

The earthquake query is a magnitude- and area-filtered historical selection, not a complete sequence, hazard forecast, damage estimate or shaking map. Equal-size markers indicate event locations. Focus follows the new event; previous locations remain present. Coastline resolution is geographic context only. Date/step headings round elapsed minutes to the nearest minute; precise UTC timestamps remain in annotations and source data.

## Reproduce and validate offline

`node scripts/real-data.mjs --verify` checks both layers of hashes and repeats all transformations from the committed raw responses. `pnpm validate` also validates every spec and checks generated JSON against the authoring modules. Missing/duplicate/nonfinite or incomplete GDP observations fail rather than being filled or interpolated. Invalid event coordinates and unsupported Japan geometry fail.

`node scripts/real-data.mjs --pin` is an explicit maintainer operation after acquiring raw files from the manifest URLs. It regenerates extracted files and hashes, preserving retrieval timestamps when raw hashes are unchanged. Upstream historical data can be revised, so a new acquisition is a reviewed dataset update, not the reproduction path. Run `pnpm examples:export` after an intentional update, review claims and hashes, and run the complete release gate. Never run `--pin` automatically in CI to bless drift.

The raw Natural Earth countries response is retained solely for offline reproducibility; only the small Japan extract enters the Studio bundle. Raw source responses, provenance scripts and canonical examples are excluded from the packed engine runtime.
