# Table / Matrix / KPI

VizForge must support BI components, not only charts.

Table:
- typed alignment/formatting
- variance
- status icon
- data bar
- sparkline
- subtotal/total treatment

Matrix:
- row/column hierarchy
- subtotals/grand totals
- measure formatting
- conditional emphasis

KPI:
- current value
- comparison
- target
- variance
- status
- optional sparkline
- optional contribution story

Do not implement lineage inside these components.
A dashboard can place a Datapass lineage Figure next to a VizForge KPI/chart.
