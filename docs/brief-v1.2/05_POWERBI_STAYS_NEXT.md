V1.2 should make the web/story/spec foundation stronger first.

After V1.2 is accepted, the first Power BI proof should reuse the same engine:

`Power BI DataView -> thin adapter -> canonical VizForge spec -> existing D3 renderer -> SVG`

Start later with one or two families such as:
- animated ranking;
- time-series comparison;
- KPI contribution.

Do not create alternate Power BI geometry.
