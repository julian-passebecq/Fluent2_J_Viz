# Bounded V1.5 gallery and story packs

Start only after real Datapass integration and refactor are green.

Target roughly 14-15 strong families and at least 20 canonical visual/story examples.

Prioritize:
1. bump / rank evolution;
2. histogram / distribution;
3. small multiples;
4. stacked area / normalized composition;
5. choropleth or proportional-symbol map.

Beeswarm, interval/range and treemap are optional if the first set is already solid.

Create reusable story templates for multi-series time comparison, ranking evolution, scatter/bubble evolution, event/map timeline and cross-family chapters.

Validate with bounded Story Packs such as:
- stock/market comparison over time;
- GDP/country metric comparison;
- processor performance / AI energy-consumption evolution;
- earthquake/event map story;
- generic category/franchise timeline story.

Use real/open data only when source/license/provenance can be pinned. Otherwise use clearly labeled synthetic fixtures. Do not invent factual claims.

Every story needs message-first title, concise takeaway, direct labels where practical, sparse legend, stable-ID annotations, source/note, readable paused state, phone annotation simplification and reduced-motion stepping.

Do not build a full scrollytelling CMS yet. Step-based StorySpec remains the core.
